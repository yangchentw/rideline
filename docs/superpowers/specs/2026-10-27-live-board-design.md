# 活動即時看板設計

## 目的與使用對象

活動進行中，任何持有活動連結的人都能查看各打卡點進度與已／未打卡名單，不需要登入或加入活動。以手機瀏覽為主，電腦可查看完整總覽。

## 方案選擇

- 已選定：新增獨立「即時看板」分頁，集中查看站點與名單，並提供直接開啟看板的分享連結。
- 未採用：直接調整活動總覽。雖然入口較直接，但地圖、活動說明和名單會讓手機頁面較長。

## 畫面與操作

1. 頁首顯示活動名稱、參加人數、已出發人數、完成全部站點人數與尚未出發人數。
2. 各站依既有路線順序呈現，顯示站名、里程、已打卡／未打卡人數、進度條與最近打卡時間。
3. 點選站點，在同頁顯示該站人員名單，可切換全部、已打卡、未打卡並搜尋姓名。點選已／未打卡人數時直接套用對應篩選。
4. 已打卡者顯示該站首次抵達時間；未打卡者顯示最近打卡站點與時間，沒有任何紀錄時顯示「尚無打卡紀錄」。
5. 手機採站點在上、名單在下的排列；電腦採站點與名單左右並排。文字和操作按鈕適合觸控，不要求橫向捲動才能閱讀名單。
6. 看板提供分享連結；以活動 ID 與看板分頁參數直接開啟，不包含 QR Code 憑證或管理權杖。

## 資料與同步

- 沿用現有公開活動資料與每 15 秒同步，不新增資料表或新的管理權限。
- 顯示實際最後成功更新時間；同步失敗時保留既有資料並提示。示範模式明示資料僅存在此瀏覽器。
- 同步時保留目前站點、名單篩選、搜尋文字與捲動位置。切換活動時重設該活動的看板條件。
- 人數分母為目前已加入的全體參加者；「未打卡」僅代表該站沒有紀錄，不判定落後、失聯或異常。
- 已結束活動仍可瀏覽，顯示結束狀態。空名單、無符合搜尋結果與無站點皆有明確提示。

## 實作邊界與驗收

沿用現有 React、Vite 與視覺風格。保留總覽、參加者與打卡點頁面的用途，打卡及管理操作沿用原本權限。此變更不包含部署、推播、GPS 定位、逾時判定或修改打卡紀錄。

驗收包括：未登入者以分享連結直接開啟、站點人數與名單一致、篩選與姓名搜尋、同步後條件保留、同步失敗提示，以及手機與電腦排版。執行專案測試與正式建置，並在瀏覽器檢查手機／電腦畫面。
